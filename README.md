# Talari Lasya — Half Saree Ceremony Invitation

Premium cinematic React/Vite invitation website.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Replace photos
Drop Lasya's real photos into `public/photos/` using these filenames:
- photo-01.jpg
- photo-02.jpg
- photo-03.jpg
- photo-04.jpg
- photo-05.jpg

## Optional music
Place an instrumental MP3 at `public/music/instrumental.mp3`. Music is never autoplayed; the visitor must enable it.

## GitHub Pages
The Vite base is `./`, so the generated `dist/` can be deployed to GitHub Pages. A GitHub Actions workflow is included.
